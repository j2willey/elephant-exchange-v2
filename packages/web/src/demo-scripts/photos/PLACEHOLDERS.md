# Demo script photos

The photos the demo scripts post. Until a file named here exists in this folder, the guided replay draws a placeholder card showing the description instead. Each description doubles as the brief for the real picture: a casual phone-camera snapshot, no brand names, no real people's faces that could be recognized.

To add a real picture, save it here under the file name shown. Keep it small (about 1600 px on the long side, under 300 KB, JPEG).
